# README hero artwork

`skillroster-hero.png` is an AI-generated conceptual illustration created on
2026-09-07 with the built-in image generation tool. It is shared by the Chinese
and English READMEs. The artwork illustrates one logical Library, selected
per-Agent Rosters, on-demand discovery, and reversible changes. The cards are
illustrative, not a screenshot, benchmark, or recommended Agent-specific policy.

## Art direction and prompt

Create a premium editorial product hero banner for SkillRoster. Deep ink navy,
warm ivory typography, mint-green accents, restrained amber, tactile capability
cards and archive trays. Large readable wordmark and the copy “One library.
The right skills for every agent.” A central Library connects to three curated
trays labelled Codex, Claude Code, and Pi. Additional capability cards remain
in the Library, with a magnifying glass suggesting on-demand discovery. Include
“Preview. Apply. Undo.” with a return arrow. Generous margins and strong
contrast. No numerical performance claims, fake screenshots, robots, neon glow,
or third-party brand logos. Keep essential product copy available as README
text and localized image alt text.

The generated PNG is retained at its native 1774 × 887 resolution. A future
revision should preserve the local relative image links used by both READMEs.
